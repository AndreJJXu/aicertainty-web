03 / Method + principles

Declared.
Sourced. Bounded.

Make human state a first-class input to AI.

First-class means a human-state inference enters a system the way any serious input does: declared, sourced, and bounded. One loop instruments the whole path.

  1. 01

    Sense→

    Name the signal and the instrument that produced it.

  2. 02

    Model→

    State the construct the signal is supposed to index.

  3. 03

    Calibrate→

    Anchor the reading in population, context, and uncertainty.

  4. 04

    Adapt→

    Let the system respond only inside the declared boundary.

  5. 05

    Verify↺

    Check that the response holds. Adaptation without verification is drift.

Evidence before confidence.

No number without provenance; no claim without its boundary.

A signal is not a human state.

The state is an inference, and the inference is where responsibility begins.

Uncertainty is data.

A confidence band, a contested link, an honest null: results, not embarrassments.
