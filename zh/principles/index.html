我们如何理解人类状态

信号不等于人类状态。

皮电不等于压力，光标停顿不等于犹豫。状态是在信号基础上建立的推断，主张与责任都从推断开始。本页说明本站使用这些术语的方式。

六项原则

P1

信号不等于人类状态。

测量是输入，而不是答案。皮电、眼动、音高、选择反应时都是信号；人类状态则是在信号基础上形成的推断。把信号直接写成状态，本身就混淆了概念。

实践中： 本站每个人类状态术语都应对应明确的构念、信号与推断边界；否则不将其表述为状态。

P2

不确定性也是数据。

置信带、有争议的关联、如实报告的零结果，都是结果。隐藏不确定性的系统是在索取信任，而不是接受检验。

实践中： 以与测量同等的视觉分量呈现不确定性；条件性零结果与其检验范围、回应变异一起完整呈现。

P3

让证据可核查，而非声称看透人心。

我们不承诺知道一个人的感受。我们承诺让关于人的主张可以被核查：构念是什么、信号是什么、证据是什么、边界在哪里。这是我们所追求的确定性。

实践中： 本站仅在品牌名称或这条原则中使用“确定性”一词。

P4

人类状态应成为核心输入。

关于人的推断会作为输入进入智能系统，无论是否有人明确说明。将其作为核心输入，意味着声明构念、命名信号、说明证据与边界，而不是让它成为模型未经标注的副作用。

实践中： 本站讨论每项人类状态推断时，都附上明确声明。

P5

以闭环为工作单元：感知 → 建模 → 校准 → 适应 → 验证。

测量不会在数值出现时结束，只有系统对数值的回应经过验证，才算闭环。缺少验证的适应可能产生漂移。

实践中： 将五个阶段作为完整闭环呈现，而非功能清单。

P6

主张边界也是研究贡献的一部分。

缺少边界的结果容易被过度解读。说明研究未能证明什么，不是结尾附上的免责声明，而是结果的一部分。

实践中： 本站每项研究都呈现其边界：“✓ 已建立 / ✗ 明确不主张”，与发现具有同等视觉分量。

如何标注主张

本站实证主张使用以下五层标签，并在相邻位置说明：

  • 已建立的背景知识

    独立于我们的成熟科学知识。作为背景，不作为本项目结果的证明。

  • 有证据支持的项目研究

    本研究计划中通过评审或已发表、且明确说明证据的发现。

  • 当前工作

    正在开发的内容与活跃稿件，明确标注状态。状态不是研究结果。

  • 假设

    可检验的预期，同时说明什么检验可能将其证伪。

  • 长期愿景

    公开的探索方向，属于愿景，不表示能力已经实现。

不因措辞更动听而提升证据层级。如果一句话只有夸大证据才成立，就删除这句话。
