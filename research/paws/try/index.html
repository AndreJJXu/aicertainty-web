PAWS · Run it yourself

Try PAWS

Connect a model you already have access to, edit a patient profile, and generate a clinical interview with the same multi-agent pipeline used in the study. Then let an independent judge read the PHQ-9 profile back from the dialogue alone.

  • Two ways to run it: the default model, provided from the author's research quota (2 runs a day per network), or your own API key, in which case requests go straight from your browser to your provider and this site receives nothing.
  • Your provider bills you. Twelve turns take roughly 50–85 model calls.
  • Same engine as the research code: identical prompts, validation and state rules (PAWS 2f0d815), checked request by request against the Python version.
  • For research only. The patient is simulated; nothing here diagnoses or treats anyone. Question 12 screens for thoughts of death or self-harm.
01

Connect your model

Any OpenAI-compatible chat-completions endpoint that allows browser requests. Tested to accept browser requests: DeepSeek, OpenAI, Alibaba Model Studio, Moonshot, SiliconFlow, Volcengine Ark, OpenRouter and Gemini. Zhipu and Anthropic's API block browser requests.

The default model is ECNU's ecnu-max, provided from the author's research quota at East China Normal University. Requests pass through an AI Certainty relay on Alibaba Cloud (Hong Kong), which forwards them to the university's model service. The relay stores no profiles or dialogues and logs no content; your IP address is used only in memory to apply the limits. Up to 12 turns per run and 2 runs per day per network; a 12-turn run takes about 4–7 minutes. For more, use your own key.

Advanced settings

Defaults follow config.yaml, except max output tokens: the research default of 15,000 exceeds many providers' limits. Automatic sends thinking: disabled only to DeepSeek models.

03

Run the interview

The fixed question schedule (in the study's original Chinese)
  1. 可以简单介绍一下你的年龄、学业或工作情况吗？
  2. 你这次主要是因为什么不舒服来就诊的？这种不舒服大概从什么时候开始的？持续了多长时间？
  3. 这段时间你心情低落、空虚、麻木或者高兴不起来的情况有多频繁？如果有类似情况的话，通常会在什么情境下更明显？
  4. 你对以前感兴趣或者愿意做的事情，现在还有兴趣吗？这种提不起兴趣的情况大概有多频繁，具体表现是什么？
  5. 你最近一天通常都怎么过？和以前相比，活动量、主动性有什么变化吗？这种变化大概有多频繁？
  6. 你最近睡眠问题有多频繁？如果有的话，具体是入睡困难、夜间醒来、早醒、睡得太少、睡得太多，还是白天困倦？
  7. 你最近食欲或体重变化有多频繁？如果有，具体是吃不下、吃太多、吃饭不香，还是体重明显变化？
  8. 你最近疲倦、没精力、身体沉重或者什么都不想动的情况有多频繁？如果有的话，具体会怎么影响你一天的状态？
  9. 你做事和思考的速度有没有变化？如果有的话，这种情况有多频繁，比如反应变慢、说话变少，或者坐立不安、心里烦躁？
  10. 你的注意力和记忆力最近怎么样？如果变差的话，这种难以集中、容易走神或记不住事情的情况有多频繁？
  11. 你有没有觉得自己做错了事、拖累别人、对不起家人，或者觉得自己很没用？如果有的话，这些想法大概有多频繁？
  12. 你有没有觉得活着没意思，或者出现过不想活、伤害自己的想法？这种想法出现过吗？出现几次？最近有多频繁？
  13. 这些状态对你的工作、学习、家务、自我照顾、社交和出门见人有影响吗？如果有影响的话，哪些方面受影响最明显？

04

Interview

    Independent PHQ-9 read-back

    A separate judge saw only the questions and answers, not the targets. Item scores run from 0 (not at all) to 3 (nearly every day); targets were compared afterwards in your browser.

    Profiles and dialogues are in Chinese, as in the study. Each run starts with an empty rule library. A run can be stopped at any time; finished turns stay on the page until you leave it. Downloads match the Python engine's dialog.json and dialog.txt formats.
